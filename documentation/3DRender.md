# 3D Rendering
## Scene Setup
Setup the 3D scene for JavaFX, including the Qubic grid. Implement some basic lighting and define the 3D x's and o's.

## Render
A dynamic 3D render of the Qubic appears below the input boards and updates in real time.

## Camera Controls
In the 3D view, the user can pan and rotate the camera to inspect different angles. 
Add mouse controls for rotation, zoom, and panning.
